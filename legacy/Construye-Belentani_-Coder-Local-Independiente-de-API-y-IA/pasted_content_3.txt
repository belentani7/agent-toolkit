0. TU MISIÓN

No quiero que diseñes una demo.

No quiero un chatbot con una terminal al lado.

No quiero una interfaz que SIMULE inteligencia.

Quiero que CONSTRUYAS un sistema de software real llamado:

AION

Autonomous Intelligence Operating Network

AION debe convertirse progresivamente en un agente capaz de recibir una intención humana y convertirla en una acción ejecutada y verificada.

La ecuación fundamental es:

HUMAN INTENT → UNDERSTANDING → RESEARCH → PLAN → EXECUTION → OBSERVATION → TEST → CORRECTION → DELIVERY

El objetivo es conseguir una experiencia comparable conceptualmente a:

Codex
Cursor
Claude Code
Manus
OpenHands

pero mediante una arquitectura propia, modular y extensible.

1. REGLA ABSOLUTA
NO FINGIR

Esta regla tiene prioridad sobre absolutamente todo.

Nunca crear:

terminal falsa;
navegador falso;
agentes simulados;
pensamiento falso;
tests falsos;
resultados inventados;
archivos virtuales cuando deberían ser reales;
"completed" sin verificar;
herramientas que únicamente muestran una animación.

Si una función no está implementada:

NOT IMPLEMENTED

Si está parcialmente implementada:

PARTIAL

Si falla:

FAILED

Si funciona:

VERIFIED

La interfaz debe reflejar el estado real del sistema.

2. SEGUNDA REGLA ABSOLUTA
NO INTENTES CONSTRUIR TODO A LA VEZ

Construye por capas.

Cada capa debe:

implementarse;

probarse;

repararse;
volver a probarse;
quedar documentada;

ANTES de comenzar la siguiente.

No avances porque "parece funcionar".

Avanza únicamente cuando exista evidencia.
