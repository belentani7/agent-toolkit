## 💡 APRENDIZAJES CLAVE

### Sobre Tokens y Contexto
- Contexto grande = más tokens de input = más costo
- Solución: usar qwen3.6-flash (32K) para tareas simples
- Reservar qwen3.8-max (1M) para tareas complejas
- En OpenClaw, el contexto incluye herramientas y archivos inyectados

### Sobre Auditoría de Repos
- Dos pasadas: triage (rápido) + deep (solo críticos)
- Sesión fresca por repo evita contaminación de contexto
- Prompt caching máximo con prefijo estático
- Timeout por repo evita bloqueos

### Sobre APIs de IA
- APIs chinas son más baratas y tienen free tiers generosos
- Pollinations AI es GRATIS ILIMITADO para imágenes
- Groq tiene free tier generoso y es ultra rápido
- HuggingFace tiene muchos modelos open source gratuitos

### Sobre Contribuciones Open Source
- Empezar con documentación y traducciones
- Buscar issues con label "good first issue"
- Ser constructivo y positivo en los PRs
- Documentar bien los cambios
