## 🏗️ Proyectos insignia

### 1. Belentani Nexus ⭐ (caso técnico flagship)
Plataforma all-in-one estilo Cabina.AI/HappyTime con estética cyberpunk. Integra **50+ modelos de IA** con **Qwen 3.8 Max como motor flagship** vía DashScope (endpoint compatible OpenAI). Incluye frontend MVP con chat multi-modelo, selector de modelos (texto/imagen/video/audio) y sistema de créditos transparente.
- Arquitectura documentada: 35+ APIs
- Driver PowerShell de auditoría masiva de 200+ repos con Qwen Code
- 10 prompts fullstack reutilizables (ZAI_PROMPTS)

### 2. ManosAbiertas ❤️ (caso de impacto social)
Plataforma educativa **100% gratuita para migrantes**: **3,686+ recursos en 39 idiomas**. Demuestra que la IA y el cloud abiertos pueden servir a personas fuera de la burbuja tecnológica con presupuesto cero. Complementada por **Cruzando-el-Charco**, guía para migrantes LGTBIQ+.

### 3. Duck Studio 🎵 (caso creativo)
Suite de producción musical con IA: generación (ACE-Step) + separación de stems (Demucs). Respaldo de carrera musical con **36M+ streams**. Material base para talleres de "open AI for culture".

### 4. Belentani OS / Omega 🌐
Portal unificado del ecosistema con GitHub Pages (9+ repos activos). Punto de entrada público navegable de todo el trabajo.

### 5. Ecosistema de agentes 🤖
150+ skills instalados y operativos (Qwen Code y CLIs compatibles), práctica diaria de desarrollo agente-first sobre modelos Qwen.
