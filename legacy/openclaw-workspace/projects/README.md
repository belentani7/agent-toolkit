# Proyectos Belentani

Este directorio contiene todos los proyectos activos del ecosistema Belentani.

## Estructura

```
projects/
├── belentani-portal/          # Portal web principal de Belentani
├── belentani7-profile/        # Perfil profesional de GitHub
├── duck-music-studio/         # Estudio de producción musical con IA
├── qwen-code/                 # Configuración y personalizaciones de Qwen Code
├── qwen-code-docs-es/         # Documentación en español para Qwen Code
├── transformers/              # Contribuciones a Hugging Face Transformers
└── first-contributions/       # Primera contribución open source
```

## Proyectos Activos

### belentani-portal
Portal web principal del ecosistema Belentani. Incluye la experiencia JUDAS_OS y todas las interfaces del universo Belentani.

### belentani7-profile
Perfil profesional de GitHub con README optimizado, estadísticas y presentación del ecosistema.

### duck-music-studio
Estudio de producción musical potenciado por IA. Integración con ACE-Step para generación de música y Demucs para separación de stems.

### qwen-code
Configuraciones, skills y personalizaciones para Qwen Code CLI. Incluye optimizaciones de token y workflows personalizados.

### qwen-code-docs-es
Traducción y documentación en español para Qwen Code. Contribución oficial al ecosistema Qwen.

### transformers
Contribuciones al repositorio Hugging Face Transformers. Incluye traducciones, mejoras de documentación y fixes.

### first-contributions
Proyecto de prueba para primera contribución open source.

## Proyectos Planeados

- **ManosAbiertas**: Plataforma educativa para migrantes
- **Cruzando-el-Charco**: Guía para migrantes LGTBIQ+
- **Judas Experience**: Experiencia musical cyberpunk
- **Belentani OS**: Sistema operativo artístico

## Cómo Agregar un Nuevo Proyecto

1. Crear carpeta con el nombre del proyecto
2. Incluir README.md explicando el proyecto
3. Documentar dependencias y setup
4. Actualizar este README si es necesario
