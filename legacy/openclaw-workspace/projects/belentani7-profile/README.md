## 👋 About Me

I'm **Pedro Belentani** — an AI Creative Technologist, digital artist, and educator.
I build living software: cyberpunk terminals, generative music engines, and AI-powered
tools that serve real communities — from migrants and the LGTBIQ+ community to
independent artists. For me, code is a creative medium: every project is tuned to
432 Hz, rooted in purpose, and shipped with heart. 🎛️✨
