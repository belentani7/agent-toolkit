# Idiomas 1-1: Presentarte como un pro

## Presentaciones básicas

### Formal
```
Buenos días/tardes. Me llamo [Nombre]. 
Soy de [País]. Mucho gusto.
```

### Informal
```
¡Hola! Soy [Nombre]. 
¿Y tú? / ¿Cómo te llamas?
```

### En una entrevista de trabajo
```
Buenos días. Mi nombre es [Nombre Completo]. 
Soy [profesión] con [X] años de experiencia. 
Es un placer estar aquí.
```

## Frases esenciales

### Saludos
| Situación | Frase |
|-----------|-------|
| Mañana | Buenos días |
| Tarde | Buenas tardes |
| Noche | Buenas noches |
| Informal | ¡Hola! / ¡Hey! |
| Al conocer a alguien | Mucho gusto / Encantado/a |
| Despedida | Adiós / Hasta luego / Hasta pronto |

### Información personal
```
Me llamo...          = Mi nombre es...
Soy de...            = Vengo de...
Tengo ... años       = Mi edad es...
Vivo en...           = Mi domicilio está en...
Estoy aquí porque... = El motivo de mi visita es...
```

### Profesión
```
Soy [profesión]
Trabajo de [profesión]
Me dedico a [actividad]
Estoy buscando trabajo como [puesto]
```

### Idiomas
```
Hablo [idioma]       
Entiendo un poco de [idioma]
Estoy aprendiendo español
Mi idioma materno es [idioma]
Hablo [idioma1] y [idioma2]
```

## Diálogos prácticos

### En la cola del banco
```
- Buenos días, ¿qué necesita?
- Buenas días. Quiero abrir una cuenta bancaria.
- ¿Tiene cita previa?
- No, ¿se puede sin cita?
- Sí, espere aquí por favor.
- Gracias.
```

### Presentarte a un vecino
```
- ¡Hola! Soy tu nuevo vecino. Me llamo Carlos.
- ¡Hola Carlos! Yo soy María. Bienvenido.
- Muchas gracias. Somos de Colombia.
- ¡Qué bien! ¿Acabáis de llegar?
- Sí, llevamos dos semanas.
- Si necesitáis algo, aquí estamos.
- Muy amable, gracias.
```

### En una entrevista
```
- Buenos días, siéntese por favor.
- Gracias. Buenos días.
- Cuénteme sobre usted.
- Soy ingeniero industrial con 8 años de experiencia 
  en gestión de proyectos. En mi país trabajé para 
  una multinacional. Estoy muy interesado en esta 
  posición porque...
```

## Pronunciación básica

### Vocales (siempre iguales en español)
- A: como "a" en "casa"
- E: como "e" en "mesa"
- I: como "i" en "mi"
- O: como "o" en "todo"
- U: como "u" en "uno"

### Consonantes difíciles

| Letra | Sonido | Ejemplo |
|-------|--------|---------|
| Ñ | como "nh" en portugués | España, año |
| R suave | entre vocal | caro, pero |
| R fuerte | al inicio o RR | rojo, perro |
| J | como "h" aspirada | jefe, jardín |
| LL | como "y" | calle, pollo |
| C (e,i) | como "z" | cine, casa |
| Z | como "z" inglesa o "s" | zapato |
| V | igual que B | vino, bueno |

### Acento
- El acento tónico va normalmente en la penúltima sílaba
- Si lleva tilde (´), se acentúa esa sílaba
- Ejemplo: MÁ-ri-a, co-ra-ZÓN, TEL-é-fo-no

## Consejos para comunicarte

1. **Habla despacio**: Mejor lento y claro que rápido e incomprensible
2. **No tengas miedo**: Los españoles aprecian que intentes hablar su idioma
3. **Pide que repitan**: "¿Puede repetir, por favor?"
4. **Pide que hablen más despacio**: "¿Puede hablar más despacio?"
5. **Usa gestos**: La comunicación no verbal ayuda mucho
6. **Sonríe**: Una sonrisa abre puertas

## Errores comunes

❌ **Confundir ser/estar**: "Soy cansado" ❌ → "Estoy cansado" ✅
❌ **Género**: "El mesa" ❌ → "La mesa" ✅
❌ **Conjugación**: "Yo es" ❌ → "Yo soy" ✅
❌ **Falsos amigos**: "Embarazada" ≠ "Embarrassed" (significa "pregnant")

## Ejercicios

1. **Preséntate en 30 segundos**: Nombre, origen, profesión, por qué estás aquí
2. **Practica con el espejo**: Mírate mientras te presentas
3. **Grábate**: Escúchate y corrige
4. **Practica con nativos**: Pide a alguien que te escuche

---

**Recuerda**: Cada vez que te presentas, estás practicando. ¡Aprovecha cada oportunidad!
