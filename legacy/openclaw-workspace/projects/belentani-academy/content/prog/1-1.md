# Programación 1-1: ¿Qué es HTML? (y por qué mola)

## ¿Qué es HTML?

HTML significa **HyperText Markup Language** (Lenguaje de Marcado de Hipertexto).

No te asustes por el nombre. En palabras sencillas:

**HTML es el esqueleto de todas las páginas web.**

Cuando ves una página web, lo que ves es:
- **HTML**: La estructura (títulos, párrafos, imágenes, enlaces)
- **CSS**: El estilo (colores, tamaños, posiciones)
- **JavaScript**: La interactividad (botones que hacen cosas, animaciones)

## Analogía: Una casa

Piensa en una página web como una casa:

- **HTML** = Los ladrillos, paredes, habitaciones (la estructura)
- **CSS** = La pintura, decoración, muebles (el aspecto visual)
- **JavaScript** = La electricidad, el agua, los electrodomésticos (lo que funciona)

Sin HTML, no hay casa. Es lo primero que necesitas.

## ¿Por qué mola aprender HTML?

1. **Es fácil**: No necesitas ser un genio de las matemáticas
2. **Es rápido**: En 10 minutos puedes crear tu primera página
3. **Es útil**: Puedes hacer tu propia web, tu CV online, un portfolio...
4. **Es la base**: Si sabes HTML, aprender CSS y JavaScript es más fácil
5. **Es gratis**: Solo necesitas un navegador y un editor de texto

## ¿Cómo funciona HTML?

HTML usa **etiquetas** para decirle al navegador qué es cada cosa:

```html
<h1>Esto es un título grande</h1>
<p>Esto es un párrafo de texto normal.</p>
<img src="foto.jpg" alt="Mi foto">
<a href="https://google.com">Esto es un enlace</a>
```

### Anatomía de una etiqueta

```html
<etiqueta>Contenido</etiqueta>
```

- **`<etiqueta>`**: Abre la etiqueta
- **`Contenido`**: Lo que va dentro (texto, imagen, etc.)
- **`</etiqueta>`**: Cierra la etiqueta (con la barra `/`)

### Ejemplos

```html
<!-- Un título -->
<h1>Bienvenido a mi web</h1>

<!-- Un párrafo -->
<p>Soy María y estoy aprendiendo a programar.</p>

<!-- Un enlace -->
<a href="https://belentani.org">Visita Belentani</a>

<!-- Una imagen -->
<img src="mi-foto.jpg" alt="Foto de María">
```

## Las etiquetas más importantes

### Títulos
```html
<h1>Título principal (el más grande)</h1>
<h2>Subtítulo</h2>
<h3>Sub-subtítulo</h3>
<h4>Y así hasta h6</h4>
```

### Texto
```html
<p>Esto es un párrafo.</p>
<strong>Texto en negrita (importante)</strong>
<em>Texto en cursiva (énfasis)</em>
<br> <!-- Salto de línea -->
```

### Enlaces
```html
<a href="https://ejemplo.com">Texto del enlace</a>
<a href="pagina2.html">Enlace a otra página</a>
<a href="#seccion1">Enlace a una sección de esta página</a>
```

### Imágenes
```html
<img src="foto.jpg" alt="Descripción de la imagen">
```
- `src`: Dónde está la imagen (ruta o URL)
- `alt`: Texto alternativo (importante para accesibilidad)

### Listas
```html
<!-- Lista sin orden (viñetas) -->
<ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ul>

<!-- Lista numerada -->
<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
  <li>Tercer paso</li>
</ol>
```

### Contenedores
```html
<div>
  <!-- Agrupa contenido (bloque) -->
  <p>Esto es un bloque de contenido.</p>
</div>

<span>
  <!-- Agrupa contenido en línea -->
  Texto <span style="color: red">en rojo</span>
</span>
```

## Estructura básica de una página HTML

Toda página HTML tiene esta estructura:

```html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi Primera Página</title>
</head>
<body>
  
  <h1>¡Hola mundo!</h1>
  <p>Esta es mi primera página web.</p>
  
</body>
</html>
```

### ¿Qué significa cada parte?

- `<!DOCTYPE html>`: Le dice al navegador que es HTML5
- `<html>`: La raíz de todo el documento
- `<head>`: Información sobre la página (no se ve)
  - `<meta charset>`: Codificación de caracteres (para que se vean bien las ñenas, acentos, etc.)
  - `<meta name="viewport">`: Para que se vea bien en móviles
  - `<title>`: El título que aparece en la pestaña del navegador
- `<body>`: Todo lo que se ve en la página

## Tu primera página HTML

### Paso 1: Crea el archivo

1. Abre el Bloc de notas (Windows) o TextEdit (Mac)
2. O mejor: descarga VS Code (gratis) desde code.visualstudio.com

### Paso 2: Escribe el código

```html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi Primera Página</title>
</head>
<body>
  
  <h1>¡Hola! Soy María</h1>
  
  <p>Soy de Colombia y vivo en Barcelona.</p>
  
  <h2>Mis hobbies</h2>
  <ul>
    <li>Cocinar</li>
    <li>Bailar</li>
    <li>Leer</li>
  </ul>
  
  <h2>Mi comida favorita</h2>
  <p>La <strong>bandeja paisa</strong> me encanta.</p>
  
  <p>Visita mi <a href="https://instagram.com">Instagram</a>.</p>
  
</body>
</html>
```

### Paso 3: Guarda el archivo

- Nombre: `index.html`
- Tipo: Todos los archivos
- Codificación: UTF-8

### Paso 4: Ábrelo

- Haz doble click en el archivo
- Se abrirá en tu navegador
- ¡Verás tu página web!

## Consejos

1. **Sangría**: Usa 2 espacios para indentar (hace el código más legible)
2. **Comentarios**: `<!-- Esto es un comentario -->` no se ve en la página
3. **Minúsculas**: Las etiquetas van en minúsculas
4. **Cierra las etiquetas**: No olvides el `</` al final
5. **Atributos**: Van dentro de la etiqueta de apertura: `<img src="foto.jpg">`

## Errores comunes

❌ **Olvidar cerrar etiquetas**: `<p>Texto` (falta `</p>`)
❌ **Nesting incorrecto**: `<strong><em>Texto</strong></em>` (debe ser `<strong><em>Texto</em></strong>`)
❌ **Españoles en atributos**: `<a href="página.html">` (usa `pagina.html` sin ñenas)
❌ **No poner alt en imágenes**: `<img src="foto.jpg">` (siempre pon `alt="descripción"`)
