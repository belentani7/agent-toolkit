# Office 2-3: Gráficos que cuentan historias

## ¿Por qué usar gráficos?

Un gráfico bien hecho puede:
- Mostrar tendencias de un vistazo
- Comparar datos fácilmente
- Convencer en una presentación
- Hacer tu trabajo más profesional

## Tipos de gráficos y cuándo usarlos

### Gráfico de barras/columnas

**Cuándo**: Comparar categorías
**Ejemplo**: Ventas por mes, gastos por categoría

```
Gastos mensuales
━━━━━━━━━━━━━━━━━━━━━━
Enero   ████████████ 1200€
Febrero ██████████   1000€
Marzo   ███████████  1100€
Abril   █████████████████ 1700€
```

### Gráfico circular (tarta)

**Cuándo**: Mostrar proporciones de un total
**Ejemplo**: Distribución de gastos, cuota de mercado

**Regla**: Máximo 5-6 categorías. Si hay más, agrupa.

### Gráfico de líneas

**Cuándo**: Mostrar evolución en el tiempo
**Ejemplo**: Ingresos anuales, temperatura mensual

### Gráfico de área

**Cuándo**: Como líneas pero enfatizando volumen
**Ejemplo**: Acumulado de ventas

### Gráfico de dispersión

**Cuándo**: Relación entre dos variables
**Ejemplo**: Horas estudiadas vs notas

## Crear un gráfico paso a paso

### Paso 1: Preparar los datos

Organiza tus datos en tablas limpias:

```
     A           B
1  Mes        Ventas
2  Enero      15000
3  Febrero    18000
4  Marzo      22000
5  Abril      19000
```

### Paso 2: Seleccionar los datos

- Selecciona incluyendo encabezados (A1:B5)
- Los encabezados se convierten en etiquetas

### Paso 3: Insertar el gráfico

1. **Insertar → Gráficos**
2. Elige el tipo recomendado
3. Click en el gráfico

### Paso 4: Personalizar

#### Título
- Click en el título → escribe el nuevo
- Posición: Arriba, centrado

#### Ejes
- Click en el eje → Formato de eje
- Cambiar escala, orientación, etiquetas

#### Leyenda
- Posición: Abajo, derecha, izquierda
- O eliminar si solo hay una serie

#### Colores
- Click en las barras/líneas → Color de relleno
- Usa colores que contrasten bien

## Gráficos profesionales

### Reglas de oro

1. **Un gráfico = una idea**: No intentes mostrar todo en uno
2. **Título descriptivo**: "Ventas Q1 2024" no "Datos"
3. **Etiquetas claras**: Que se entienda sin explicación
4. **Colores consistentes**: Mismo color = misma categoría
5. **Menos es más**: Elimina elementos innecesarios

### Elementos que puedes añadir

- **Etiquetas de datos**: Mostrar valores exactos
- **Líneas de cuadrícula**: Ayudan a leer valores
- **Barras de error**: Para datos estadísticos
- **Línea de tendencia**: Para ver la dirección general
- **Eje secundario**: Para datos con escalas diferentes

### Diseño limpio

**Elimina**:
- Bordes innecesarios
- Efectos 3D (dificultan la lectura)
- Demasiados colores
- Leyenda si solo hay una serie

**Añade**:
- Espacio en blanco
- Etiquetas directas (en vez de leyenda)
- Anotaciones para puntos importantes

## Errores comunes en gráficos

❌ **Gráfico 3D**: Distorsiona las proporciones
❌ **Demasiadas series**: Confunde al lector
❌ **Sin título**: ¿De qué son los datos?
❌ **Escala engañosa**: Empezar el eje Y en un valor distinto de 0
❌ **Colores que no contrastan**: No se distinguen las barras
❌ **Tarta con muchas porciones**: Usa barras si hay más de 5 categorías

## Consejos prácticos

1. **Elige el gráfico correcto**: Barras para comparar, líneas para tiempo, tarta para proporciones
2. **Ordena los datos**: De mayor a menor (excepto series temporales)
3. **Usa colores con significado**: Verde = bueno, Rojo = malo
4. **Añade contexto**: "Aumento del 20% respecto al mes anterior"
5. **Prueba diferentes tipos**: A veces un gráfico de líneas funciona mejor que uno de barras

## Gráficos dinámicos

### Tablas dinámicas con gráfico

1. Selecciona tus datos
2. **Insertar → Tabla dinámica**
3. Arrastra campos a filas, columnas, valores
4. Con la tabla seleccionada: **Analizar → Gráfico dinámico**

### Ventaja

Puedes cambiar qué datos se muestran sin recrear el gráfico.
