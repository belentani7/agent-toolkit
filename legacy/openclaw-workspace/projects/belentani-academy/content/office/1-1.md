# Office 1-1: Word en 10 minutos - Lo esencial

## ¿Qué es Word?

Microsoft Word es un procesador de textos. Básicamente, es donde escribes documentos: cartas, CVs, informes, trabajos...

## La interfaz básica

Cuando abres Word, verás:

```
┌─────────────────────────────────────────┐
│  [Archivo] [Inicio] [Insertar] ...    │
├─────────────────────────────────────────┤
│  [A] [B] [I] [U]  [Fuente ▼] [12 ▼]  │
├─────────────────────────────────────────┤
│                                         │
│                                         │
│         [Tu documento aquí]             │
│                                         │
│                                         │
└─────────────────────────────────────────┘
```

- **Arriba**: Menú con todas las herramientas
- **Debajo**: Barra de herramientas rápidas (formato)
- **Centro**: Tu página en blanco

## Atajos que DEBES saber

| Atajo | Acción | Cuándo usarlo |
|-------|--------|---------------|
| `Ctrl + S` | Guardar | CADA 5 MINUTOS |
| `Ctrl + Z` | Deshacer | Cuando te equivocas |
| `Ctrl + Y` | Rehacer | Cuando deshaces de más |
| `Ctrl + C` | Copiar | Copiar texto |
| `Ctrl + V` | Pegar | Pegar texto copiado |
| `Ctrl + X` | Cortar | Mover texto |
| `Ctrl + A` | Seleccionar todo | Seleccionar todo el documento |
| `Ctrl + B` | Negrita | Resaltar texto |
| `Ctrl + I` | Cursiva | Énfasis |
| `Ctrl + U` | Subrayado | Resaltar |

## Formato básico

### Cambiar fuente y tamaño

1. Selecciona el texto
2. En la barra de herramientas:
   - Cambia la fuente (ej: Arial, Calibri, Times New Roman)
   - Cambia el tamaño (ej: 11, 12, 14)

### Alineación

- **Izquierda**: Texto normal (por defecto)
- **Centro**: Títulos, encabezados
- **Derecha**: Firmas, fechas
- **Justificado**: Texto formal (alineado a ambos lados)

### Espaciado

- **Interlineado**: Espacio entre líneas (1.0, 1.5, 2.0)
- **Espaciado antes/después**: Espacio entre párrafos

## Guardar tu documento

### Primera vez:
1. `Ctrl + S` o Archivo → Guardar como
2. Elige dónde guardarlo (Escritorio, Documentos, etc.)
3. Ponle un nombre claro: `CV_Juan_Perez_2024.docx`
4. Click en "Guardar"

### Después:
- Solo `Ctrl + S` y se guarda automáticamente

### Formatos de archivo:
- `.docx`: Formato Word (el normal)
- `.pdf`: Para enviar (no se puede editar)
- `.txt`: Solo texto, sin formato

## Insertar elementos

### Imágenes
1. Insertar → Imágenes
2. Elige la imagen de tu ordenador
3. Ajusta el tamaño arrastrando las esquinas

### Tablas
1. Insertar → Tabla
2. Selecciona cuántas filas y columnas necesitas
3. Escribe el contenido en cada celda

### Encabezados y pies de página
1. Insertar → Encabezado / Pie de página
2. Elige un diseño o crea el tuyo
3. Útil para: número de página, tu nombre, fecha

## Revisar ortografía

Word subraya en rojo las palabras mal escritas:
- **Click derecho** sobre la palabra → sugerencias
- **F7**: Abre el revisor ortográfico completo

## Consejos pro

1. **Guarda frecuentemente**: `Ctrl + S` es tu mejor amigo
2. **Usa estilos**: Para títulos y subtítulos (Inicio → Estilos)
3. **Vista previa**: Antes de imprimir, ve a Archivo → Imprimir para ver cómo queda
4. **Plantillas**: Word tiene plantillas para CVs, cartas, etc. (Archivo → Nuevo)

## Errores comunes

❌ **No guardar**: Pierdes todo si se cierra Word
❌ **Usar Enter para espaciado**: Usa espaciado de párrafo, no Enter múltiples veces
❌ **Texto sin formato al pegar**: Usa `Ctrl + Shift + V` para pegar sin formato
