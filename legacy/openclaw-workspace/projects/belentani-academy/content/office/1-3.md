# Office 1-3: Tablas, índices y referencias

## Tablas en Word

### ¿Cuándo usar tablas?

- Comparar información
- Organizar datos
- Crear horarios o calendarios
- Presentar información estructurada

### Insertar una tabla

1. **Insertar → Tabla**
2. Mueve el ratón para seleccionar filas y columnas
3. Click para insertar

### Formato de tabla

#### Bordes y sombreado
- Selecciona la tabla
- **Diseño de tabla → Bordes**: elige estilo
- **Sombreado**: cambia color de celdas

#### Alineación de texto
- Click dentro de una celda
- Usa los botones de alineación (izquierda, centro, derecha)
- Para centrar verticalmente: **Diseño de tabla → Alineación → Centrar**

### Consejos para tablas profesionales

1. **Encabezados en negrita**: La primera fila siempre visible
2. **Bordes sutiles**: No uses bordes gruesos
3. **Alternar colores**: Filas alternas para facilitar la lectura
4. **Tamaño consistente**: Misma altura para todas las filas

## Índice automático

### ¿Qué es un índice automático?

Una lista de contenidos que se genera automáticamente a partir de los títulos de tu documento. Si cambias algo, el índice se actualiza solo.

### Paso 1: Aplicar estilos a los títulos

Antes de crear el índice, debes dar formato a tus títulos:

1. Selecciona tu título
2. En **Inicio → Estilos**, elige:
   - **Título 1**: Para títulos principales
   - **Título 2**: Para subtítulos
   - **Título 3**: Para sub-subtítulos

### Paso 2: Insertar el índice

1. Coloca el cursor donde quieres el índice (normalmente al principio)
2. **Referencias → Tabla de contenido**
3. Elige un estilo automático

### Paso 3: Actualizar el índice

Si modificas el documento:
1. Click en el índice
2. **Actualizar tabla**
3. Elige "Actualizar toda la tabla"

### Ejemplo de estructura con estilos

```
[Estilo: Título 1] Introducción
[Estilo: Título 1] Capítulo 1: Contexto
  [Estilo: Título 2] 1.1 Antecedentes
  [Estilo: Título 2] 1.2 Objetivos
[Estilo: Título 1] Capítulo 2: Metodología
  [Estilo: Título 2] 2.1 Enfoque
  [Estilo: Título 2] 2.2 Herramientas
[Estilo: Título 1] Conclusiones
```

## Referencias y citas

### Insertar citas

1. **Referencias → Insertar cita → Agregar nueva fuente**
2. Rellena los datos del libro/artículo/web
3. Word genera la cita automáticamente

### Estilos de citación

- **APA**: El más usado en ciencias sociales
- **MLA**: Usado en humanidades
- **Chicago**: Usado en historia y negocios

Para cambiarlo: **Referencias → Estilo** → elige el que necesites

### Bibliografía automática

1. Al final del documento
2. **Referencias → Bibliografía**
3. Word genera la lista de todas tus citas

## Numeración de páginas

### Insertar números de página

1. **Insertar → Número de página**
2. Elige posición:
   - **Principio de página**: Arriba
   - **Final de página**: Abajo
   - **Márgenes**: En los lados

### Formatos

- Números simples: 1, 2, 3...
- Con sección: Página 1 de 10
- Romanos: i, ii, iii...

### Empezar desde un número diferente

Si quieres que la página 5 sea la "1":
1. **Insertar → Número de página → Formato del número de página**
2. En "Iniciar en", pon el número deseado

## Notas al pie

### ¿Qué son?

Notas que aparecen al final de la página para aclarar algo o dar una referencia.

### Insertar nota al pie

1. Coloca el cursor donde quieres la referencia
2. **Referencias → Insertar nota al pie**
3. Escribe tu nota

### Diferencia entre nota al pie y nota al final

- **Nota al pie**: Aparece abajo de la misma página
- **Nota al final**: Aparece al final del documento

## Marcadores y enlaces internos

### Crear un marcador

1. Selecciona el texto o coloca el cursor
2. **Insertar → Marcador**
3. Ponle un nombre (sin espacios)

### Enlazar a un marcador

1. Selecciona el texto del enlace
2. **Insertar → Vínculo**
3. Elige "Lugar de este documento"
4. Selecciona el marcador

### Útil para

- Ir de una sección a otra
- Crear índices personalizados
- Enlazar a tablas o figuras

## Combinar correspondencia

### ¿Qué es?

Crear múltiples documentos personalizados a partir de una plantilla y una lista de datos.

### Ejemplo: Cartas personalizadas

Tienes 100 clientes y quieres enviar una carta a cada uno con su nombre.

1. **Correspondencia → Iniciar combinación → Cartas**
2. **Seleccionar destinatarios → Usar una lista existente** (Excel)
3. Inserta campos: **Insertar campo de combinación → Nombre**
4. **Finalizar y combinar** → genera 100 cartas

## Atajos útiles para documentos largos

| Atajo | Acción |
|-------|--------|
| `Ctrl + G` | Ir a (página, sección, marcador) |
| `Ctrl + F` | Buscar texto |
| `Ctrl + H` | Buscar y reemplazar |
| `Ctrl + Shift + F8` | Modo de selección especial |
| `F4` | Repetir última acción |

## Consejos para documentos profesionales

1. **Usa estilos SIEMPRE**: Facilita índices, formatos consistentes y cambios rápidos
2. **Guarda versiones**: `Documento_v1.docx`, `Documento_v2.docx`
3. **Revisa ortografía**: `F7` antes de enviar
4. **Vista previa**: `Ctrl + P` para ver cómo queda impreso
5. **Protege el documento**: `Revisar → Proteger documento` si es sensible
