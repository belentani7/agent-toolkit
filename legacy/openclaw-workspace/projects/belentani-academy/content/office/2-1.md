# Office 2-1: Excel no da miedo - Promesa

## ¿Qué es Excel?

Excel es una **hoja de cálculo**: una cuadrícula gigante donde puedes:
- Organizar datos (listas, presupuestos, inventarios)
- Hacer cálculos automáticos (sumas, promedios, porcentajes)
- Crear gráficos visuales
- Automatizar tareas repetitivas

## La interfaz

```
     A          B          C          D
  ┌──────────┬──────────┬──────────┬──────────┐
1 │ Nombre   │ Precio   │ Cantidad │ Total    │
  ├──────────┼──────────┼──────────┼──────────┤
2 │ Arroz    │ 2.50     │ 3        │ =B2*C2   │
  ├──────────┼──────────┼──────────┼──────────┤
3 │ Pan      │ 1.20     │ 5        │ =B3*C3   │
  ├──────────┼──────────┼──────────┼──────────┤
4 │ Leche    │ 0.80     │ 2        │ =B4*C4   │
  └──────────┴──────────┴──────────┴──────────┘
```

### Conceptos clave

- **Celda**: Cada cuadrito (ej: A1, B2, C3)
- **Columna**: Vertical (A, B, C, D...)
- **Fila**: Horizontal (1, 2, 3, 4...)
- **Hoja**: Una pestaña de cálculo (Sheet1, Sheet2...)
- **Libro**: El archivo completo (contiene varias hojas)

## Tu primera hoja de cálculo

### Paso 1: Abrir Excel

- Abre Excel o ve a office.com/excel (gratis online)
- Elige "Libro en blanco"

### Paso 2: Entender la celda activa

- La celda con borde verde es la **celda activa**
- Puedes escribir directamente en ella
- Usa las **flechas del teclado** para moverte

### Paso 3: Escribir datos

Haz click en A1 y escribe:
```
Producto
```
Presiona Enter (te mueve abajo) y escribe:
```
Arroz
```
Sigue con: Pan, Leche, Huevos, Aceite

### Paso 4: Añadir más columnas

En B1 escribe: `Precio`
En C1 escribe: `Cantidad`
En D1 escribe: `Total`

Llena los datos:
| Producto | Precio | Cantidad |
|----------|--------|----------|
| Arroz    | 2.50   | 3        |
| Pan      | 1.20   | 5        |
| Leche    | 0.80   | 2        |
| Huevos   | 3.00   | 1        |
| Aceite   | 4.50   | 2        |

### Paso 5: Tu primera fórmula

En D2 (primera celda de "Total"), escribe:
```
=B2*C2
```
Presiona Enter. ¡Aparece 7.50!

### Paso 6: Copiar la fórmula

- Click en D2
- En la esquina inferior derecha hay un cuadradito verde (controlador de relleno)
- Arrástralo hacia abajo hasta D6
- ¡Las fórmulas se copian automáticamente!

## Conceptos fundamentales

### Tipos de datos

| Tipo | Ejemplo | Cómo se ve |
|------|---------|------------|
| Texto | "Hola" | Alineado a la izquierda |
| Número | 42 | Alineado a la derecha |
| Fecha | 15/03/2024 | Alineado a la derecha |
| Fórmula | =A1+B1 | Resultado del cálculo |

### Operadores básicos

| Operador | Significado | Ejemplo | Resultado |
|----------|-------------|---------|-----------|
| + | Suma | =5+3 | 8 |
| - | Resta | =10-4 | 6 |
| * | Multiplicación | =3*4 | 12 |
| / | División | =10/2 | 5 |
| ^ | Potencia | =2^3 | 8 |

### Referencias de celdas

Cuando escribes una fórmula, usas **referencias**:
- `A1`: Celda A1
- `A1:B5`: Rango de A1 a B5
- `A:A`: Toda la columna A
- `1:1`: Toda la fila 1

## Formato de celdas

### Números

1. Selecciona las celdas
2. Click derecho → **Formato de celdas**
3. Elige categoría:
   - **Número**: Decimales, separador de miles
   - **Moneda**: € $ £
   - **Porcentaje**: 50%
   - **Fecha**: Diferentes formatos

### Bordes y colores

- **Inicio → Bordes**: Añade bordes a tus celdas
- **Color de relleno**: Cambia el fondo de las celdas
- **Color de fuente**: Cambia el color del texto

### Ajustar ancho de columna

- Doble click en la línea entre columnas (arriba)
- O arrastra para ajustar manualmente

## Errores comunes

❌ **Confundir texto con número**: "100" (texto) ≠ 100 (número)
❌ **Olvidar el = en fórmulas**: `B2*C2` no funciona, debe ser `=B2*C2`
❌ **Referencias circulares**: =A1 dentro de A1
❌ **No usar $ para fijar celdas**: Cuando copias fórmulas, las referencias cambian

## Consejos para principiantes

1. **Empieza simple**: No intentes hacer fórmulas complejas al principio
2. **Usa nombres claros**: "Precio", "Cantidad" en vez de "A", "B"
3. **Congela paneles**: `Vista → Inmovilizar` para ver los encabezados al hacer scroll
4. **Guarda frecuentemente**: Ctrl+S es tu amigo
5. **Practica con datos reales**: Tu presupuesto mensual, una lista de compras...
