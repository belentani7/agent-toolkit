# Office 2-2: Fórmulas que te salvan la vida

## Las 10 fórmulas esenciales

### 1. SUMA - Sumar valores

```excel
=SUMA(A1:A10)
```
Suma todos los valores de A1 a A10.

**Ejemplo real**: Sumar todos tus gastos del mes.

### 2. PROMEDIO - Media aritmética

```excel
=PROMEDIO(B1:B20)
```
Calcula la media de los valores.

**Ejemplo real**: Calcular tu gasto medio diario.

### 3. MAX y MIN - Valores extremos

```excel
=MAX(C1:C100)    ' El valor más alto
=MIN(C1:C100)    ' El valor más bajo
```

**Ejemplo real**: Encontrar tu mayor gasto y tu menor ingreso.

### 4. CONTAR - Contar celdas

```excel
=CONTAR(A1:A100)      ' Cuenta celdas con números
=CONTARA(A1:A100)     ' Cuenta celdas no vacías
=CONTAR.SI(A1:A100;">1000")  ' Cuenta si cumple condición
```

**Ejemplo real**: Contar cuántos meses gastaste más de 1000€.

### 5. SI - Tomar decisiones

```excel
=SI(A1>1000;"Alto";"Bajo")
```
Si A1 es mayor que 1000, muestra "Alto"; si no, "Bajo".

**Ejemplo real**: Clasificar gastos como "Alto" o "Normal".

### 6. BUSCARV - Buscar datos

```excel
=BUSCARV(D1;A1:B100;2;FALSO)
```
Busca D1 en la columna A y devuelve el valor correspondiente de la columna B.

**Ejemplo real**: Buscar el precio de un producto por su nombre.

### 7. CONCATENAR - Unir textos

```excel
=CONCATENAR(A1;" ";B1)
' O simplemente:
=A1&" "&B1
```

**Ejemplo real**: Juntar nombre y apellidos.

### 8. HOY y AHORA - Fecha y hora

```excel
=HOY()     ' Fecha actual
=AHORA()   ' Fecha y hora actual
```

**Ejemplo real**: Calcular cuántos días han pasado desde una fecha.

### 9. REDONDEAR - Redondear números

```excel
=REDONDEAR(A1;2)    ' Redondea a 2 decimales
```

**Ejemplo real**: Redondear precios con IVA.

### 10. CONTAR.SI.CONJUNTO - Contar con múltiples condiciones

```excel
=CONTAR.SI.CONJUNTO(A1:A100;">100";B1:B100;"Comida")
```
Cuenta celdas donde A > 100 Y B = "Comida".

## Fórmulas para la vida real

### Presupuesto mensual

```excel
Ingresos:     =SUMA(B2:B5)
Gastos:       =SUMA(C2:C20)
Disponible:   =B7-C7
Ahorro %:     =(B7-C7)/B7
```

### Calcular edad

```excel
=DATEDIF(B2;HOY();"Y")
```
Donde B2 es tu fecha de nacimiento.

### Calcular días entre fechas

```excel
=C2-B2
```
Donde B2 es fecha inicio y C2 es fecha fin.

### Calcular IVA

```excel
Precio sin IVA:  =A1/1.21
IVA incluido:    =A1*1.21
Solo IVA:        =A1*0.21
```

### Calcular porcentaje

```excel
% del total:     =A1/SUMA(A:A)
Aumento %:       =(B1-A1)/A1
Descuento:       =A1*(1-B1/100)
```

### Préstamo / Hipoteca

```excel
=PAGO(tasa/12;nper*12;-pv)
```
- tasa: interés anual
- nper: años
- pv: cantidad prestada

## Referencias absolutas vs relativas

### El problema

Cuando copias una fórmula, las referencias cambian:
```
=B2*C2  → al copiar abajo → =B3*C3
```

### La solución: $

```excel
=B2*$E$1
```
- `B2`: Referencia relativa (cambia al copiar)
- `$E$1`: Referencia absoluta (NO cambia al copiar)

### Cuándo usar cada una

| Tipo | Cuándo usar | Ejemplo |
|------|-------------|---------|
| Relativa (A1) | La mayoría de casos | Copiar fórmulas fila a fila |
| Absoluta ($A$1) | Cuando referencias una celda fija | Un tipo de IVA, un objetivo |
| Mixta ($A1 o A$1) | Casos avanzados | Tablas de doble entrada |

## Funciones lógicas avanzadas

### SI anidado

```excel
=SI(A1>=90;"Sobresaliente";SI(A1>=70;"Notable";SI(A1>=50;"Aprobado";"Suspenso")))
```

### Y / O

```excel
=SI(Y(A1>18;B1="Sí");"Mayor de edad con permiso";"No cumple")
=SI(O(A1="Español";A1="Portugués");"Hispanohablante";"Otro idioma")
```

### SI.ERROR - Manejar errores

```excel
=SI.ERROR(A1/B1;"Error en división")
```
Si A1/B1 da error, muestra "Error en división" en vez de #DIV/0!

## Consejos para dominar fórmulas

1. **Empieza con lo básico**: SUMA, PROMEDIO, SI
2. **Usa el asistente**: Click en fx junto a la barra de fórmulas
3. **Verifica resultados**: ¿Tiene sentido el número?
4. **Nombra rangos**: `Fórmulas → Definir nombre` para hacer fórmulas más legibles
5. **Protege fórmulas**: `Revisar → Proteger hoja` para que nadie borre tus fórmulas

## Errores comunes en fórmulas

| Error | Significado | Solución |
|-------|-------------|----------|
| #¡DIV/0! | División por cero | Verifica el denominador |
| #¿NOMBRE? | Nombre mal escrito | Revisa la ortografía de la función |
| #¡VALOR! | Tipo de dato incorrecto | Usa números donde se esperan números |
| #REF! | Referencia inválida | No borres celdas referenciadas |
| #N/A | Valor no disponible | Verifica BUSCARV, datos existen |
