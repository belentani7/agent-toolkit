# Office 3-2: Diseño que no da vergüenza

## Los 4 principios del diseño

### 1. Contraste

**Haz que los elementos importantes destaquen**

- Títulos grandes, texto normal pequeño
- Colores oscuros sobre fondo claro (o viceversa)
- Negritas para lo importante

**Ejemplo**:
```
❌ Todo en el mismo tamaño y color
✅ Título en 36pt azul oscuro, texto en 18pt negro
```

### 2. Alineación

**Todo debe estar alineado con algo**

- Usa guías invisibles para alinear elementos
- Texto a la izquierda (más legible)
- Elementos alineados entre sí

**Ejemplo**:
```
❌ Elementos dispersos por toda la diapositiva
✅ Todo alineado a una cuadrícula invisible
```

### 3. Repetición

**Mantén consistencia visual**

- Mismos colores en toda la presentación
- Mismas fuentes
- Mismo estilo de imágenes

**Ejemplo**:
```
❌ Cada diapositiva con colores y fuentes diferentes
✅ Paleta de 2-3 colores repetida en toda la presentación
```

### 4. Proximidad

**Agrupa elementos relacionados**

- Lo que está cerca se percibe como relacionado
- Espacio entre grupos diferentes

**Ejemplo**:
```
❌ Título lejos del contenido al que se refiere
✅ Título pegado al contenido, espacio antes del siguiente grupo
```

## Tipografía

### Fuentes seguras (funcionan en todos los ordenadores)

**Sans-serif (modernas, limpias)**:
- Arial
- Calibri
- Helvetica
- Verdana
- Tahoma

**Serif (clásicas, formales)**:
- Times New Roman
- Georgia
- Garamond

### Combinaciones ganadoras

**Moderna y profesional**:
- Títulos: Montserrat Bold
- Texto: Open Sans Regular

**Elegante**:
- Títulos: Playfair Display
- Texto: Lato

**Técnica**:
- Títulos: Roboto Bold
- Texto: Roboto Light

### Reglas de tipografía

1. **Máximo 2 fuentes**: Una para títulos, otra para texto
2. **Tamaños jerárquicos**:
   - Título: 36-44pt
   - Subtítulo: 24-28pt
   - Texto: 18-24pt
   - Notas: 14-16pt
3. **No uses más de 2 colores de texto**: Negro + un color de acento
4. **Evita**: Cursivas para texto largo, todo en mayúsculas, fuentes decorativas

## Layout: Cómo organizar elementos

### Regla de los tercios

Divide la diapositiva en 9 partes (3x3):

```
┌─────┬─────┬─────┐
│     │     │     │
├─────┼─────┼─────┤
│     │  X  │     │  ← Puntos de interés en las intersecciones
├─────┼─────┼─────┤
│     │     │     │
└─────┴─────┴─────┘
```

Coloca los elementos importantes en las intersecciones.

### Tipos de layout

**Dividido (50/50)**:
```
┌──────────┬──────────┐
│          │          │
│  Texto   │  Imagen  │
│          │          │
└──────────┴──────────┘
```

**Imagen completa con texto superpuesto**:
```
┌────────────────────────┐
│                        │
│      [Imagen fondo]    │
│                        │
│    [Texto encima]      │
│                        │
└────────────────────────┘
```

**Grid (cuadrícula)**:
```
┌──────┬──────┬──────┐
│  1   │  2   │  3   │
├──────┼──────┼──────┤
│  4   │  5   │  6   │
└──────┴──────┴──────┘
```

## Elementos que NUNCA debes usar

❌ **WordArt**: Parece de 1995
❌ **Clipart**: Busca fotos modernas
❌ **Fuentes Comic Sans**: Nunca, por favor
❌ **Fondos con texturas**: Distractan
❌ **Animaciones de entrada excesivas**: Una o dos máximo
❌ **Transiciones entre diapositivas locas**: "Cortina", "Avión"... no
❌ **Demasiados colores**: Máximo 3-4 en toda la presentación

## Ejemplo práctico: Rediseño

### ❌ ANTES

```
[Diapositiva con fondo azul brillante]
[Título en rojo Comic Sans 28pt]
[10 líneas de texto en negro 14pt]
[Clipart de una persona saludando]
[Bordes de colores alrededor]
```

### ✅ DESPUÉS

```
[Fondo blanco limpio]
[Título en azul oscuro, Montserrat 36pt]
[3 puntos clave en negro, Open Sans 20pt]
[Foto profesional ocupando la mitad derecha]
[Espacio en blanco generoso]
```

## Consejos finales

1. **Menos es más**: Elimina todo lo que no sea esencial
2. **Consistencia**: Mismos colores, fuentes y estilos en toda la presentación
3. **Contraste**: Asegúrate de que el texto se lee bien
4. **Espacio en blanco**: No llenes cada rincón
5. **Imágenes de calidad**: Pixeladas = poco profesional
6. **Prueba en proyector**: Lo que se ve bien en pantalla puede verse mal proyectado
