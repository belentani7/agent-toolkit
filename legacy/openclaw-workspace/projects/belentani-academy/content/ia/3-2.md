# IA 3-2: Prompts para tu trabajo

## Búsqueda de empleo

### Optimizar tu CV
```
CONTEXTO: Soy [tu profesión] de [tu país], con [X] años de experiencia. Vivo en [ciudad española] hace [tiempo].

TAREA: Revisa este CV y sugiere mejoras para el mercado laboral español.

FORMATO: Lista de cambios concretos con explicación de por qué cada mejora ayuda.

[PEGA TU CV AQUÍ]
```

### Carta de presentación
```
CONTEXTO: Estoy aplicando a un puesto de [puesto] en [empresa]. Mi experiencia principal es [experiencia relevante].

TAREA: Escribe una carta de presentación de máximo 250 palabras que destaque:
- Mi motivación por este sector
- Mis habilidades transferibles
- Mi situación como persona migrante (positivamente: diversidad, idiomas, resiliencia)

FORMATO: Tono profesional pero cercano. Evita clichés.
```

### Preparar entrevista
```
CONTEXTO: Tengo entrevista para [puesto] en [tipo de empresa] mañana.

TAREA: 
1. Dame las 10 preguntas más probables que me harán
2. Para cada una, sugiere cómo responder considerando que soy migrante
3. Dame 3 preguntas inteligentes que yo puedo hacerles

FORMATO: Lista con pregunta + ejemplo de respuesta + consejos
```

### Email de seguimiento
```
CONTEXTO: Tuve una entrevista hace 3 días y aún no me han respondido.

TAREA: Escribe un email de seguimiento profesional pero no desesperado.

FORMATO: Máximo 80 palabras. Tono cordinal. Recordar brevemente mi interés y disponibilidad.
```

## En el trabajo

### Entender instrucciones complejas
```
CONTEXTO: Mi jefe me dio estas instrucciones [pegar instrucciones] pero no entiendo todo.

TAREA: 
1. Explícame qué significa cada parte
2. Identifica lo que no está claro
3. Sugiere preguntas que puedo hacer para aclarar

FORMATO: Lista punto por punto con explicaciones sencillas.
```

### Redactar emails profesionales
```
CONTEXTO: Necesito escribir un email a [destinatario] sobre [tema]. El tono debe ser [formal/informal].

TAREA: Redacta el email considerando que el español no es mi lengua materna pero quiero sonar profesional.

FORMATO: Email completo con asunto. Máximo [X] palabras.
```

### Resolver conflictos
```
CONTEXTO: Tengo un conflicto con un compañero porque [situación].

TAREA: 
1. Analiza la situación objetivamente
2. Dame 3 opciones de cómo abordarlo
3. Para cada opción, dame un guion de qué decir

FORMATO: Opciones con pros/contras y frases exactas que puedo usar.
```

### Pedir aumento o mejores condiciones
```
CONTEXTO: Llevo [tiempo] en la empresa, he logrado [logros]. Quiero pedir [aumento/cambio].

TAREA: Ayúdame a preparar la conversación:
- Argumentos sólidos
- Cómo abordar el tema
- Qué hacer si dicen que no

FORMATO: Guion paso a paso con posibles respuestas y cómo reaccionar.
```

## Productividad

### Organizar tu semana
```
CONTEXTO: Esta semana tengo estas tareas: [lista]. También trabajo [horas] y tengo [compromisos personales].

TAREA: Créame un plan realista para la semana.

FORMATO: Calendario día por día con horarios, incluyendo descansos. Prioriza por urgencia/importancia.
```

### Resumir documentos largos
```
CONTEXTO: Tengo este documento de [tipo] que necesito entender pero es muy largo/técnico.

TAREA: 
1. Dame un resumen ejecutivo de máximo 200 palabras
2. Lista los 5 puntos más importantes
3. Identifica qué es relevante para mi situación como [tu situación]

FORMATO: Estructura clara con headers.

[PEGA DOCUMENTO]
```

### Aprender algo nuevo para el trabajo
```
CONTEXTO: En mi trabajo necesito saber [habilidad/herramienta]. Mi nivel actual es [nivel].

TAREA: Créame un plan de aprendizaje de 2 semanas (30 min/día).

FORMATO: Día por día con: qué aprender, recurso gratuito recomendado, ejercicio práctico.
```

## Consejos generales

1. **Sé específico sobre tu contexto**: Cuanto más sepa la IA de tu situación, mejor te ayuda
2. **Pide ejemplos concretos**: No teorías, cosas que puedas usar YA
3. **Itera**: Si la primera respuesta no es perfecta, pide ajustes
4. **Guarda tus prompts buenos**: Crea una carpeta con los que te funcionan

---

**Recuerda**: La IA es tu asistente personal. Úsala para todo: desde escribir emails hasta negociar tu salario.
