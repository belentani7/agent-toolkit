# IA 3-3: Prompts para la vida diaria

## Trámites y gestiones

### Preparar una cita en extranjería
```
CONTEXTO: Tengo cita en la oficina de extranjería el [fecha] para [trámite].

TAREA: 
1. Lista de documentos que necesito llevar
2. Qué esperar del proceso
3. Frases útiles en español para la cita
4. Qué hacer si falta algún documento

FORMATO: Checklist práctico + mini-glosario de términos.
```

### Entender una carta oficial
```
CONTEXTO: Me ha llegado esta carta de [organismo] y no entiendo qué me piden.

TAREA: 
1. Explica qué dice la carta en lenguaje sencillo
2. Qué tengo que hacer y en qué plazo
3. Qué pasa si no lo hago

FORMATO: Resumen en 3 puntos + acción concreta que debo tomar.

[PEGA CARTA O FOTO]
```

## Salud

### Preparar visita médica
```
CONTEXTO: Tengo cita con el médico por [motivo]. No soy muy bueno explicando síntomas en español.

TAREA: 
1. Dame vocabulario médico básico para mi situación
2. Ayúdame a describir mis síntomas claramente
3. Preguntas importantes que debo hacer al médico

FORMATO: Lista de frases útiles + vocabulario con pronunciación.
```

### Entender recetas o informes
```
CONTEXTO: Me han dado este informe médico/receta y no entiendo todo.

TAREA: Explica en lenguaje sencillo qué dice y qué debo hacer.

FORMATO: Puntos clave + acciones a tomar + qué preguntar al médico si tengo dudas.

[PEGA INFORME]
```

## Educación de hijos

### Ayudar con deberes
```
CONTEXTO: Mi hijo/a está en [curso] y tiene que hacer [tarea]. Yo no entiendo bien el sistema educativo español.

TAREA: 
1. Explícame qué tiene que hacer
2. Ayúdame a ayudarle (sin hacerle los deberes)
3. Dame recursos gratuitos para apoyar su aprendizaje

FORMATO: Explicación paso a paso + enlaces a recursos educativos gratuitos.
```

### Comunicarte con el colegio
```
CONTEXTO: Necesito escribir al profesor/tutor de mi hijo sobre [tema].

TAREA: Redacta un email respetuoso y claro.

FORMATO: Email formal pero accesible. Máximo 150 palabras. Tono colaborativo.
```

## Finanzas personales

### Presupuesto mensual
```
CONTEXTO: Gano [cantidad] al mes. Mis gastos fijos son: alquiler [X], facturas [Y], comida [Z].

TAREA: 
1. Ayúdame a crear un presupuesto realista
2. Identifica dónde puedo ahorrar
3. Sugiere apps gratuitas para controlar gastos

FORMATO: Tabla con ingresos/gastos + consejos prácticos de ahorro.
```

### Entender una factura
```
CONTEXTO: Me ha llegado esta factura de [luz/agua/gas/internet] y me parece muy alta.

TAREA: 
1. Explica los conceptos de la factura
2. Identifica si hay algo inusual
3. Dame consejos para reducir el consumo

FORMATO: Explicación sencilla + acciones concretas para ahorrar.
```

## Transporte

### Planificar un viaje
```
CONTEXTO: Necesito ir de [origen] a [destino] el [fecha]. Presupuesto limitado.

TAREA: Dame opciones de transporte ordenadas por precio:
- Tren
- Bus
- Coche compartido
- Avión (si aplica)

FORMATO: Tabla comparativa con: medio, precio estimado, duración, dónde reservar.
```

### Entender el transporte público
```
CONTEXTO: Acabo de llegar a [ciudad] y no entiendo cómo funciona el transporte.

TAREA: 
1. Explica los tipos de transporte disponibles
2. Cómo comprar billetes/abonos
3. Apps útiles
4. Trucos para ahorrar

FORMATO: Guía práctica paso a paso.
```

## Ocio y social

### Planear un evento
```
CONTEXTO: Quiero organizar una comida/reunión con [tipo de personas] el [fecha]. Presupuesto: [X].

TAREA: 
1. Sugiere ideas de actividades
2. Plan de organización paso a paso
3. Lista de compras/preparación

FORMATO: Timeline + checklist + presupuesto estimado.
```

### Recomendar planes
```
CONTEXTO: Vivo en [ciudad], es fin de semana, tengo [presupuesto], me gusta [intereses].

TAREA: Dame 5 ideas de planes variados (gratis y de pago).

FORMATO: Lista con: plan, ubicación, precio, por qué puede gustarme.
```

## Relaciones y comunidad

### Conocer gente nueva
```
CONTEXTO: Soy nuevo/a en [ciudad], soy [edad], me interesa [intereses]. Me cuesta hacer amigos.

TAREA: 
1. Sugiere formas de conocer gente
2. Apps y comunidades online
3. Eventos y grupos locales
4. Consejos para romper el hielo

FORMATO: Lista práctica con enlaces y primeros pasos concretos.
```

### Resolver malentendidos culturales
```
CONTEXTO: Tuve una situación con [persona española] y creo que hubo un malentendido cultural. [Describir situación].

TAREA: 
1. Analiza qué pudo pasar desde ambas perspectivas
2. Cómo abordar la situación
3. Qué decir para resolverlo

FORMATO: Análisis + guion de conversación + consejos generales sobre cultura española.
```

## Consejos generales

1. **La IA no sustituye profesionales**: Para temas legales, médicos o financieros graves, consulta expertos
2. **Verifica información importante**: La IA puede equivocarse
3. **Personaliza tus prompts**: Cuanto más específico seas sobre TU situación, mejor ayuda recibirás
4. **Guarda los prompts útiles**: Crea plantillas para situaciones recurrentes

---

**Recuerda**: La IA es una herramienta para hacerte la vida más fácil. Úsala sin miedo, pero con sentido común.
