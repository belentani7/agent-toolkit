# IA 3-1: La fórmula mágica del prompt perfecto

## La fórmula CTF

Un buen prompt tiene tres ingredientes:

### C - Contexto
¿Quién eres? ¿Cuál es tu situación? ¿Qué sabes del tema?

### T - Tarea
¿Qué quieres exactamente? ¿Qué debe hacer la IA?

### F - Formato
¿Cómo quieres la respuesta? ¿Larga? ¿Corta? ¿En lista? ¿En tabla?

## Ejemplo sin fórmula vs con fórmula

### ❌ Sin fórmula:
```
Ayúdame con mi CV
```
Resultado: Genérico, poco útil

### ✅ Con fórmula:
```
CONTEXTO: Soy Ahmed, tengo 30 años, soy de Marruecos y vivo en Barcelona hace 1 año. 
Trabajé 5 años como cocinero en mi país pero aquí no tengo experiencia documentada.

TAREA: Ayúdame a crear un CV para buscar trabajo de cocinero en restaurantes de Barcelona.

FORMATO: 
- Máximo 1 página
- Secciones claras: datos, experiencia, formación, idiomas
- Destaca que soy bilingüe árabe-francés y estoy aprendiendo catalán
- Tono profesional pero no rígido
```
Resultado: Específico, útil, accionable

## Técnicas avanzadas de prompting

### 1. "Actúa como..."
Dale un rol a la IA:
```
Actúa como un experto en recursos humanos especializado en contratar migrantes. 
Revisa mi CV y dime qué mejorar.
```

### 2. "Paso a paso"
Para tareas complejas:
```
Explícame paso a paso cómo empadronarme en Madrid, desde pedir cita hasta obtener el volante.
```

### 3. "Como si tuviera X años"
Para simplificar:
```
Explícame qué es el NIE como si tuviera 10 años.
```

### 4. "Dame ejemplos"
Para entender mejor:
```
Dame 5 ejemplos de emails formales para solicitar una cita en extranjería.
```

### 5. "Compara opciones"
Para decidir:
```
Compara las ventajas e inconvenientes de ser autónomo vs trabajar por cuenta ajena 
para un migrante recién llegado a España.
```

## Prompts para situaciones reales de migrantes

### Para trámites:
```
CONTEXTO: Llegué a España hace 8 meses con visado de estudiante. Quiero cambiar a permiso de trabajo.

TAREA: Explícame el proceso de modificación de estancia por residencia y trabajo.

FORMATO: Lista de pasos con requisitos específicos y plazos. Incluye enlaces oficiales si es posible.
```

### Para aprender español:
```
CONTEXTO: Soy de Rumanía, nivel A2 de español. Trabajo en limpieza y necesito comunicarme con mis jefes y compañeros.

TAREA: Dame 20 frases útiles para mi trabajo diario.

FORMATO: Tabla con: situación | frase en español | pronunciación aproximada | traducción al rumano
```

### Para emprendimiento:
```
CONTEXTO: Soy de Senegal, vivo en Sevilla. Sé hacer ropa tradicional africana y quiero venderla online.

TAREA: Dame un plan sencillo para empezar un negocio de ropa online con poco presupuesto.

FORMATO: Plan de 5 pasos, cada uno con: qué hacer, cuánto cuesta aproximadamente, y primer acción concreta.
```

## Errores que matan tu prompt

1. **No dar suficiente contexto**: La IA no es adivina
2. **Ser demasiado ambiguo**: "Escribe algo bueno" no es una tarea
3. **Olvidar el formato**: Si no dices cómo lo quieres, la IA decide (y puede no gustarte)
4. **No iterar**: El primer resultado rara vez es perfecto. Pide ajustes.

## La regla de oro

**Buen prompt = Buena respuesta**
**Mal prompt = Mala respuesta**

La IA es tan buena como las instrucciones que le das. Practica y mejorarás.
