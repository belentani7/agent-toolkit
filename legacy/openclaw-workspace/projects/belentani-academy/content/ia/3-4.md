# IA 3-4: Errores comunes al usar IA

## Error #1: Confiar ciegamente en la IA

### El problema
La IA puede "alucinar": inventar información con total confianza.

### Ejemplo real
```
Tú: ¿Cuál es la dirección de la oficina de extranjería en Barcelona?
IA: La oficina está en Carrer de la Diputació 123. (❌ DIRECCIÓN INVENTADA)
```

### La solución
**SIEMPRE verifica información importante**:
- Direcciones → Google Maps
- Teléfonos → Web oficial
- Requisitos legales → BOE o web del organismo
- Datos médicos → Profesional de salud

### Regla de oro
> Si la consecuencia de un error es grave (legal, médica, financiera), verifica SIEMPRE.

## Error #2: Dar datos personales sensibles

### El problema
La IA no es un espacio privado seguro.

### ❌ NUNCA compartas:
- Número de identificación (DNI, NIE, pasaporte)
- Datos bancarios
- Contraseñas
- Dirección exacta de tu casa
- Información médica detallada de terceros

### ✅ SÍ puedes compartir:
- Tu situación general ("soy migrante en España")
- Tu profesión ("soy electricista")
- Tu ciudad ("vivo en Barcelona")
- Tu nivel de español ("soy B1")

## Error #3: Esperar que la IA lea tu mente

### El problema
Prompts vagos = respuestas inútiles

### ❌ Mal prompt:
```
Ayúdame con papeles
```
Resultado: Respuesta genérica que no te sirve

### ✅ Buen prompt:
```
Soy de Ecuador, llevo 2 años en España con visado de estudiante. 
Quiero cambiar a permiso de residencia no lucrativa. 
¿Qué requisitos necesito y cuál es el proceso paso a paso?
```
Resultado: Respuesta específica y útil

## Error #4: No iterar

### El problema
Aceptar la primera respuesta aunque no sea perfecta

### La realidad
Los mejores resultados vienen de **conversar** con la IA:

```
Tú: Escribe un email para mi jefe pidiendo un día libre
IA: [Email genérico]
Tú: Hazlo más formal y añade que es para un trámite de extranjería
IA: [Email mejorado]
Tú: Perfecto, pero hazlo más corto
IA: [Email final]
```

### Consejo
Trata a la IA como un compañero de trabajo: conversa, refina, ajusta.

## Error #5: Usar IA para todo sin pensar

### El problema
Delegar el pensamiento crítico a la IA

### Ejemplo
```
Tú: ¿Debería aceptar este trabajo? [detalles del trabajo]
IA: Sí, deberías aceptarlo porque...
Tú: OK, lo acepto.
```

### ❌ Esto es peligroso
La IA no conoce:
- Tu situación personal completa
- Tus valores y prioridades
- El contexto real de la oferta
- Las consecuencias a largo plazo

### ✅ Mejor enfoque
```
Tú: Estoy dudando entre aceptar este trabajo o seguir buscando. 
Estos son los pros y contras que veo: [tu lista]. 
¿Qué aspectos debería considerar que quizás no estoy viendo?
```
La IA te ayuda a PENSAR, no piensa POR TI.

## Error #6: No aprovechar el contexto

### El problema
Empezar cada conversación desde cero

### La solución
Aprovecha que la IA recuerda el contexto de la conversación:

```
Tú: Soy migrante venezolano en Madrid, soy ingeniero civil
IA: Entendido
Tú: ¿Cómo puedo homologar mi título?
IA: [Respuesta específica para tu caso]
Tú: ¿Y para trabajar mientras tanto?
IA: [Recuerda tu contexto y da consejos relevantes]
```

## Error #7: Ignorar las limitaciones de formato

### El problema
La IA tiene límites:
- No puede acceder a internet en tiempo real (siempre)
- Tiene un límite de longitud de conversación
- No puede crear archivos directamente
- No recuerda conversaciones pasadas (si cierras el chat)

### Adaptarse es clave
- Para textos largos: divídelos en partes
- Para archivos: pide el contenido y guárdalo tú
- Para info actualizada: especifica "busca en internet" si la IA lo permite

## Error #8: No usar la IA para aprender

### El problema
Usar la IA solo para obtener respuestas, no para entender

### ❌ Enfoque limitado:
```
Tú: Traduce este texto [texto]
IA: [Traducción]
Tú: Gracias
```

### ✅ Enfoque de aprendizaje:
```
Tú: Traduce este texto y explícame las frases más difíciles. 
También dame 3 ejemplos más de cada estructura gramatical nueva.
```

## Checklist: Uso responsable de IA

Antes de usar una respuesta de IA, pregúntate:

- [ ] ¿Es esto información crítica (legal/médica/financiera)? → VERIFICA
- [ ] ¿He dado datos personales sensibles? → ELIMÍNALOS
- [ ] ¿Mi prompt es específico y claro? → MEJÓRALO
- [ ] ¿He pedido ajustes si la respuesta no es perfecta? → ITERA
- [ ] ¿Estoy pensando por mí mismo o delegando? → REFLEXIONA
- [ ] ¿Estoy aprendiendo o solo copiando? → APRENDE

---

**Recuerda**: La IA es una herramienta PODEROSA pero imperfecta. Úsala con inteligencia crítica.
