# PROMPT MAESTRO: UNIFICACIÓN BELENTANI OMEGA

## CONCEPTO CENTRAL
Belentani no es solo un proyecto. Es un **arquetipo viviente** que se manifiesta en múltiples dimensiones:

### 1. BELENTANI · EL ARQUETIPO
- **Identidad**: Pedro Belentani · Artista · Creador · Visionario
- **Misión**: Transformar la experiencia humana a través del arte, la tecnología y la conciencia
- **Valores**: Autenticidad, innovación, ruptura de paradigmas, integración de opuestos

### 2. JUDAS · LA PARADOJA
- **Concepto**: La traición como acto de amor supremo
- **Significado**: Sin traición no hay redención. Sin oscuridad no hay luz.
- **Manifestación**: Experiencia cyberpunk galáctica que explora la dualidad humana
- **Estética**: Glassmorphism + Neon Red + Cyberpunk + Starfield

### 3. OMEGA · LA CONVERGENCIA
- **Concepto**: Punto de integración donde todos los mundos se encuentran
- **Significado**: La unificación sin perder la diversidad
- **Manifestación**: Plataforma que conecta arte, tecnología, educación y conciencia
- **Estética**: Minimalismo elegante + tipografía monumental + transiciones fluidas

### 4. DUCK · EL ECOSISTEMA
- **Concepto**: Suite creativa de producción musical y artística
- **Significado**: Herramientas para materializar la visión creativa
- **Manifestación**: Studio Suite, Music Lab, Apps creativas
- **Estética**: Funky + retro + moderno + colorido

### 5. MANOS ABIERTAS · LA MISIÓN SOCIAL
- **Concepto**: Educación gratuita para comunidades migrantes y diversas
- **Significado**: Democratizar el acceso al conocimiento y las herramientas
- **Manifestación**: Plataforma trilingüe con cursos, CV, recursos, comunidad
- **Estética**: Accesible + cálido + profesional + inclusivo

### 6. NOIACORE · LA TECNOLOGÍA
- **Concepto**: Infraestructura tecnológica para el ecosistema creativo
- **Significado**: La base que sostiene toda la visión
- **Manifestación**: APIs, automatizaciones, herramientas de desarrollo
- **Estética**: Técnico + minimalista + funcional + escalable

### PRINCIPIOS DE DISEÑO UNIFICADOS

1. **Autenticidad Radical**: Cada proyecto debe ser una expresión genuina de la visión
2. **Integración de Opuestos**: Luz/oscuridad, arte/tecnología, individual/colectivo
3. **Excelencia Técnica**: Código limpio, performance óptimo, accesibilidad total
4. **Narrativa Coherente**: Cada proyecto cuenta una parte de la historia completa
5. **Estética Distintiva**: Cada proyecto tiene su identidad pero mantiene coherencia visual
