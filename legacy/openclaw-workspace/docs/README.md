# Documentación Belentani

Este directorio contiene la documentación central del ecosistema Belentani.

## Archivos

- **PROMPT_MAESTRO_BELENTANI.md** - Manifiesto y visión del ecosistema Belentani
- **pages-status.txt** - Estado actual de GitHub Pages de todos los repos

## Estructura del Ecosistema

El ecosistema Belentani se organiza en proyectos dentro de `projects/`:

### Proyectos Activos
- **belentani-portal/** - Portal web principal (JUDAS_OS v12.0)
- **belentani7-profile/** - Perfil profesional de GitHub
- **duck-music-studio/** - Estudio de producción musical con IA
- **qwen-code/** - Configuración y personalizaciones de Qwen Code
- **qwen-code-docs-es/** - Documentación en español para Qwen Code
- **transformers/** - Contribuciones a Hugging Face Transformers
- **first-contributions/** - Primera contribución open source

### Proyectos Planeados
- ManosAbiertas - Plataforma educativa para migrantes
- Cruzando-el-Charco - Guía para migrantes LGTBIQ+
- Judas Experience - Experiencia musical cyberpunk
- Belentani OS - Sistema operativo artístico

## Cómo Contribuir

1. Revisa la documentación en este directorio
2. Elige un proyecto en `projects/`
3. Sigue las guías de contribución de cada proyecto
4. Actualiza esta documentación si es necesario
