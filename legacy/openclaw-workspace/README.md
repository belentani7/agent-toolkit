## Proyectos Principales

### Belentani Portal
Portal web con JUDAS_OS v12.0 - interfaz terminal cyberpunk con estética glassmorphism, neón rojo y starfield.

### Duck Music Studio
Estudio de producción musical con IA usando ACE-Step para generación y Demucs para separación de stems.

### Qwen Code Docs ES
Documentación completa en español para Qwen Code CLI, incluyendo guías de configuración y workflows.
