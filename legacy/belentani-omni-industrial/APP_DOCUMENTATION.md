## 🏗️ System Architecture

The application is built using a **Full-Stack (Express + React)** architecture, leveraging **Firebase** for real-time data synchronization and **Gemini 3 Flash** for autonomous council logic.

### 1. Backend Infrastructure (`server.ts`)
The server acts as the primary entry point, handling static file serving and initial database configuration.

*   **Framework**: Express v5
*   **Production Fix**: Uses `app.get('*all', ...)` for wildcard routing to prevent `PathError` crashes in production environments.
*   **Firebase Initialization**: Robustly checks for valid configuration before attempting to connect, preventing server crashes during initial setup.

### 2. Autonomous Executive Council (`CEODashboard.tsx`)
The application is overseen by an integrated council of five AI agents (CEO, COO, CMO, CPO, CTO) operating under the **Supreme Law of Coherence**.

*   **Model**: Gemini 3 Flash (`gemini-3-flash-preview`)
*   **Capabilities**: Uses **Google Search** to analyze real-time music and tech trends.
*   **System Prompt**: Implements the **Master System Prompt** for autonomous decision-making, monetization strategy, and cross-platform coherence.
*   **Output**: Generates a JSON-formatted "Daily Strategy" including headlines, trending genres, and market analysis.
*   **Compliance**: All Gemini API calls are made from the frontend to ensure security and key management compliance.

### 3. Real-Time Synchronization (`CEOContext.tsx`)
The application uses **Firestore `onSnapshot`** to provide a reactive experience across all users.

*   **Logic**: When the Executive Council updates the strategy in Firestore, the `CEOContext` automatically pushes the new data to the UI without requiring a page refresh.
*   **State Management**: React Context API is used to distribute the strategy and system configuration globally.

### 4. Security & RBAC (`firestore.rules`)
Access control is strictly enforced via **Firebase Security Rules**.

*   **Admin Access**: Only the owner (`belentani7pedro@gmail.com`) can access the Executive Council Dashboard and trigger strategic updates.
*   **Public Data**: The `ceo_strategy` is publicly readable so users can see the "Daily Vibe," but it is only writable by the admin.
*   **Validation**: All writes are validated for schema integrity and size limits to prevent DoS attacks.

### 5. Frontend & UI/UX
*   **Styling**: Tailwind CSS with a custom dark-mode theme.
*   **Animations**: `framer-motion` for smooth, high-fidelity UI transitions.
*   **Icons**: `lucide-react` for the command center and navigation.
*   **Responsive**: Desktop-first design with mobile-first utility classes.
