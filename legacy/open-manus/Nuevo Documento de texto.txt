## 🛠️ Instalación Paso a Paso (Manual)

Si prefieres hacerlo tú mismo o el script automático falla, sigue estos pasos.

### 1. Instalar Python 3.12
1.  Descarga el instalador desde [python.org](https://www.python.org/downloads/release/python-3120/).
2.  Durante la instalación, **marca la opción "Add Python to PATH"** y, si aparece, haz clic en "Disable path length limit".
3.  Verifica la instalación abriendo una terminal (`cmd`) y ejecutando:
    ```cmd
    python --version
    ```

### 2. Instalar Git
1.  Descarga Git desde [git-scm.com](https://git-scm.com/download/win).
2.  Instálalo con las opciones por defecto.

### 3. Instalar Ollama
1.  Descarga el instalador para Windows desde [ollama.com](https://ollama.com/download/windows).
2.  Ejecuta el instalador. Ollama se ejecutará en segundo plano.
3.  Verifica que esté funcionando:
    ```cmd
    ollama --version
    ```
4.  Descarga el modelo recomendado:
    ```cmd
    ollama pull qwen2.5:7b
    ```
    > **Alternativas:** `llama3:8b` (mejor en inglés) o `qwen2.5:3b` (más ligero).

### 4. Clonar y Preparar OpenManus
1.  Clona el repositorio oficial de OpenManus:
    ```cmd
    git clone https://github.com/FoundationAgents/OpenManus.git
    cd OpenManus
    ```
2.  Crea y activa un entorno virtual:
    ```cmd
    python -m venv venv
    venv\Scripts\activate
    ```
3.  Instala `uv` para una gestión de dependencias más rápida:
    ```cmd
    pip install uv
    ```
4.  Instala las dependencias del proyecto:
    ```cmd
    uv pip install -r requirements.txt
    ```
5.  (Opcional) Instala el navegador para la automatización web:
    ```cmd
    playwright install
    ```

### 5. Configurar OpenManus para Ollama
1.  Crea el archivo de configuración desde el ejemplo:
    ```cmd
    copy config\config.example.toml config\config.toml
    ```
2.  Abre `config\config.toml` con un editor de texto (como Notepad++ o VS Code).
3.  **Reemplaza todo el contenido** con lo siguiente (ajusta el modelo si usas otro):
    ```toml
    # Configuración para usar Ollama con un modelo local
    [llm]
    model = "qwen2.5:7b"          # O "llama3:8b", "qwen2.5:3b", etc.
    base_url = "http://localhost:11434/v1"
    api_key = "ollama"            # No se usa, pero es necesario para el formato
    max_tokens = 4096
    temperature = 0.0

    # La configuración de visión puede ser la misma o apuntar a un modelo diferente
    [llm.vision]
    model = "qwen2.5:7b"
    base_url = "http://localhost:11434/v1"
    api_key = "ollama"
    max_tokens = 4096
    temperature = 0.0
    ```
    > **⚠️ Importante:** El endpoint debe ser `.../v1`, no `.../api` para la compatibilidad con la API de OpenAI que OpenManus espera.

## ⚙️ Configuración Avanzada

*   **Cambiar de Modelo:** Si descargas otro modelo (ej. `llama3.1:8b`), solo actualiza el campo `model` en ambas secciones del `config.toml`.
*   **Ajustar Parámetros:** Puedes modificar `max_tokens` (longitud de la respuesta) y `temperature` (creatividad, 0.0 = determinista, 1.0 = muy creativo).
*   **Desactivar Caché de Hugging Face:** Si usas modelos locales, puedes desactivar la caché de Hugging Face para ahorrar espacio editando `config.toml` y añadiendo:
    ```toml
    enable_hf_cache = false
    ```

python web_run.py

python main.py

```cmd
python run_mcp.py
```

## 🐛 Solución de Problemas

| Problema | Posible Solución |
| :--- | :--- |
| **`'python' no se reconoce`** | No añadiste Python al PATH. Reinstala Python y marca la opción "Add Python to PATH". |
| **`'ollama' no se reconoce`** | Asegúrate de que Ollama está instalado y en ejecución. Busca el icono en la bandeja del sistema. |
| **Error de conexión a Ollama** | Verifica que Ollama esté corriendo (`ollama serve`). Comprueba que la URL en `config.toml` es `http://localhost:11434/v1`. Revisa que el firewall de Windows no esté bloqueando el puerto 11434. |
| **El modelo no responde o da errores** | Asegúrate de que el modelo que pusiste en `config.toml` coincide con el que descargaste con `ollama pull`. Prueba con `qwen2.5:7b` que es el más estable para OpenManus. |
| **Error de dependencias (numpy, etc.)** | A veces hay conflictos. Prueba a instalar una versión específica: `uv pip install numpy==1.23.5` y luego vuelve a instalar `requirements.txt`. |
| **El agente no usa las herramientas** | Asegúrate de que el modelo soporta `function calling`. Modelos como `qwen2.5-coder` pueden tener problemas. Usa `qwen2.5:7b` o `llama3:8b`. |

## ❓ Preguntas Frecuentes (FAQ)

**¿Puedo usar otros modelos?**
Sí, cualquier modelo que Ollama soporte y que tenga buen soporte de `function calling`. Modelos como `mistral`, `llama3` o `qwen2.5` funcionan bien.

**¿Necesito una GPU?**
No es estrictamente necesario, pero la experiencia será mucho más lenta sin una. Modelos de 7B parámetros pueden funcionar aceptablemente en una CPU moderna con suficiente RAM.

**¿Es realmente gratuito?**
Sí, al 100%. No necesitas ninguna clave API de pago. Todo se ejecuta en tu propia máquina.

**¿Puedo instalar esto en macOS o Linux?**
Sí, los pasos son muy similares, solo cambian los comandos para activar el entorno virtual (`source venv/bin/activate`) y la ruta de los scripts.

**¿Qué hago si el script `setup_windows.bat` no funciona?**
Puedes seguir la [Instalación Paso a Paso (Manual)](#instalación-paso-a-paso-manual). El script es solo un atajo para automatizar esos pasos.

#### 3. `scripts/setup_windows.bat`

Script mejorado con más verificaciones y mensajes de estado.

```batch
@echo off
setlocal enabledelayedexpansion
title OpenManus Installer for Windows

echo ===================================================
echo   OpenManus + Ollama Installer for Windows 11
echo ===================================================
echo.

:: --- Check for Python ---
echo [1/6] Checking Python installation...
python --version >nul 2>&1
if errorlevel 1 (
    echo [ERROR] Python is not installed or not in PATH.
    echo Please install Python 3.12 from https://www.python.org/downloads/
    echo Make sure to check "Add Python to PATH" during installation.
    pause
    exit /b 1
)
echo [OK] Python found.
echo.

:: --- Check for Git ---
echo [2/6] Checking Git installation...
git --version >nul 2>&1
if errorlevel 1 (
    echo [ERROR] Git is not installed or not in PATH.
    echo Please install Git from https://git-scm.com/download/win
    pause
    exit /b 1
)
echo [OK] Git found.
echo.

:: --- Create Virtual Environment ---
echo [3/6] Creating Python virtual environment...
if not exist "venv" (
    python -m venv venv
    if errorlevel 1 (
        echo [ERROR] Failed to create virtual environment.
        pause
        exit /b 1
    )
    echo [OK] Virtual environment created.
) else (
    echo [OK] Virtual environment already exists.
)
echo.

:: --- Activate venv and Install Dependencies ---
echo [4/6] Activating virtual environment and installing dependencies...
call venv\Scripts\activate
if errorlevel 1 (
    echo [ERROR] Failed to activate virtual environment.
    pause
    exit /b 1
)

echo Installing uv (fast package installer)...
pip install uv --quiet
if errorlevel 1 (
    echo [WARN] Failed to install uv. Falling back to pip...
    pip install -r requirements.txt
) else (
    echo Installing dependencies with uv...
    uv pip install -r requirements.txt
)
if errorlevel 1 (
    echo [ERROR] Failed to install dependencies.
    echo Try manually: pip install -r requirements.txt
    pause
    exit /b 1
)
echo [OK] Dependencies installed.
echo.

:: --- Copy Configuration File ---
echo [5/6] Setting up configuration file...
if not exist "config\config.toml" (
    if exist "config\config.example.toml" (
        copy config\config.example.toml config\config.toml >nul
        echo [OK] Configuration file created.
    ) else (
        echo [WARN] Example configuration file not found.
        echo Please create config\config.toml manually.
    )
) else (
    echo [OK] Configuration file already exists.
)
echo.

:: --- Pull Ollama Model ---
echo [6/6] Verifying and pulling the Ollama model (qwen2.5:7b)...
echo This may take several minutes depending on your internet speed.
ollama pull qwen2.5:7b
if errorlevel 1 (
    echo [WARN] Failed to pull qwen2.5:7b.
    echo Please run manually: ollama pull qwen2.5:7b
    echo Or check that Ollama is installed and running.
) else (
    echo [OK] Model ready.
)
echo.

:: --- Final Message ---
echo ===================================================
echo Setup completed successfully!
echo.
echo You can now run OpenManus:
echo   - Web Interface: python web_run.py
echo   - CLI Mode:      python main.py
echo   - MCP Mode:      python run_mcp.py
echo ===================================================
pause
```

3.  **Reemplaza todo el contenido** con lo siguiente (ajusta el modelo si usas otro):
    ```toml
    # Configuración para usar Ollama con un modelo local
    [llm]
    model = "qwen2.5:7b"          # O "llama3:8b", "qwen2.5:3b", etc.
    base_url = "http://localhost:11434/v1"
    api_key = "ollama"            # No se usa, pero es necesario para el formato
    max_tokens = 4096
    temperature = 0.0

    # La configuración de visión puede ser la misma o apuntar a un modelo diferente
    [llm.vision]
    model = "qwen2.5:7b"
    base_url = "http://localhost:11434/v1"
    api_key = "ollama"
    max_tokens = 4096
    temperature = 0.0
    ```
    > **⚠️ Importante:** El endpoint debe ser `.../v1`, no `.../api` para la compatibilidad con la API de OpenAI que OpenManus espera.

## ⚙️ Configuración Avanzada

*   **Cambiar de Modelo:** Si descargas otro modelo (ej. `llama3.1:8b`), solo actualiza el campo `model` en ambas secciones del `config.toml`.
*   **Ajustar Parámetros:** Puedes modificar `max_tokens` (longitud de la respuesta) y `temperature` (creatividad, 0.0 = determinista, 1.0 = muy creativo).
*   **Desactivar Caché de Hugging Face:** Si usas modelos locales, puedes desactivar la caché de Hugging Face para ahorrar espacio editando `config.toml` y añadiendo:
    ```toml
    enable_hf_cache = false

## 🐛 Solución de Problemas

| Problema | Posible Solución |
| :--- | :--- |
| **`'python' no se reconoce`** | No añadiste Python al PATH. Reinstala Python y marca la opción "Add Python to PATH". |
| **`'ollama' no se reconoce`** | Asegúrate de que Ollama está instalado y en ejecución. Busca el icono en la bandeja del sistema. |
| **Error de conexión a Ollama** | Verifica que Ollama esté corriendo (`ollama serve`). Comprueba que la URL en `config.toml` es `http://localhost:11434/v1`. Revisa que el firewall de Windows no esté bloqueando el puerto 11434. |
| **El modelo no responde o da errores** | Asegúrate de que el modelo que pusiste en `config.toml` coincide con el que descargaste con `ollama pull`. Prueba con `qwen2.5:7b` que es el más estable para OpenManus. |
| **Error de dependencias (numpy, etc.)** | A veces hay conflictos. Prueba a instalar una versión específica: `uv pip install numpy==1.23.5` y luego vuelve a instalar `requirements.txt`. |
| **El agente no usa las herramientas** | Asegúrate de que el modelo soporta `function calling`. Modelos como `qwen2.5-coder` pueden tener problemas. Usa `qwen2.5:7b` o `llama3:8b`. |

## ❓ Preguntas Frecuentes (FAQ)

**¿Puedo usar otros modelos?**
Sí, cualquier modelo que Ollama soporte y que tenga buen soporte de `function calling`. Modelos como `mistral`, `llama3` o `qwen2.5` funcionan bien.

**¿Necesito una GPU?**
No es estrictamente necesario, pero la experiencia será mucho más lenta sin una. Modelos de 7B parámetros pueden funcionar aceptablemente en una CPU moderna con suficiente RAM.

**¿Es realmente gratuito?**
Sí, al 100%. No necesitas ninguna clave API de pago. Todo se ejecuta en tu propia máquina.

**¿Puedo instalar esto en macOS o Linux?**
Sí, los pasos son muy similares, solo cambian los comandos para activar el entorno virtual (`source venv/bin/activate`) y la ruta de los scripts.

**¿Qué hago si el script `setup_windows.bat` no funciona?**
Puedes seguir la [Instalación Paso a Paso (Manual)](#instalación-paso-a-paso-manual). El script es solo un atajo para automatizar esos pasos.

@echo off
setlocal enabledelayedexpansion
title OpenManus Installer for Windows

echo ===================================================
echo   OpenManus + Ollama Installer for Windows 11
echo ===================================================
echo.

    echo Please install Python 3.12 from https://www.python.org/downloads/
    echo Make sure to check "Add Python to PATH" during installation.
    pause
    exit /b 1
)
echo [OK] Python found.
echo.

:: --- Check for Git ---
echo [2/6] Checking Git installation...
git --version >nul 2>&1
if errorlevel 1 (
    echo [ERROR] Git is not installed or not in PATH.
    echo Please install Git from https://git-scm.com/download/win
    pause
    exit /b 1
)
echo [OK] Git found.
echo.

:: --- Create Virtual Environment ---
echo [3/6] Creating Python virtual environment...
if not exist "venv" (
    python -m venv venv
    if errorlevel 1 (
        echo [ERROR] Failed to create virtual environment.

        exit /b 1
    )
    echo [OK] Virtual environment created.
) else (
    echo [OK] Virtual environment already exists.
)
echo.

:: --- Activate venv and Install Dependencies ---
echo [4/6] Activating virtual environment and installing dependencies...
call venv\Scripts\activate
if errorlevel 1 (
    echo [ERROR] Failed to activate virtual environment.
    pause
    exit /b 1
)

echo Installing uv (fast package installer)...
pip install uv --quiet
if errorlevel 1 (
    echo [WARN] Failed to install uv. Falling back to pip...
    pip install -r requirements.txt
) else (
    echo Installing dependencies with uv...
    uv pip install -r requirements.txt
)
if errorlevel 1 (
    echo [ERROR] Failed to install dependencies.
    echo Try manually: pip install -r requirements.txt
    pause
    exit /b 1
)
echo [OK] Dependencies installed.
echo.

:: --- Copy Configuration File ---
echo [5/6] Setting up configuration file...
if not exist "config\config.toml" (
    if exist "config\config.example.toml" (
        copy config\config.example.toml config\config.toml >nul
        echo [OK] Configuration file created.
    ) else (
        echo [WARN] Example configuration file not found.
        echo Please create config\config.toml manually.
    )
) else (
    echo [OK] Configuration file already exists.
)
echo.

:: --- Pull Ollama Model ---
echo [6/6] Verifying and pulling the Ollama model (qwen2.5:7b)...
echo This may take several minutes depending on your internet speed.
ollama pull qwen2.5:7b
if errorlevel 1 (
    echo [WARN] Failed to pull qwen2.5:7b.
    echo Please run manually: ollama pull qwen2.5:7b
    echo Or check that Ollama is installed and running.
) else (
    echo [OK] Model ready.
)
echo.

:: --- Final Message ---
echo ===================================================
echo Setup completed successfully!
echo.
echo You can now run OpenManus:
echo   - Web Interface: python web_run.py
echo   - CLI Mode:      python main.py
echo   - MCP Mode:      python run_mcp.py
echo ===================================================
pause
