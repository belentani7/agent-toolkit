## 👥 Cómo Empezar Ya

### Si quieres usar las skills existentes:
```bash
npx skills add belentani7/skills-registry open-school
```

### Si quieres contribuir tu propia skill:
```bash
git clone https://github.com/belentani7/skills-registry.git
cd skills-registry
mkdir skills/mi-nueva-skill/
# Crear SKILL.md siguiendo SKILL-SIZING estándar
git checkout -b feat/mi-nueva-skill
git add .
git commit -m "feat(skill): add mi-nueva-skill v1.0.0"
git push origin feat/mi-nueva-skill
gh pr create --title "feat(skill): add mi-nueva-skill v1.0.0"
```
