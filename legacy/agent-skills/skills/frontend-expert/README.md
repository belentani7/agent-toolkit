# frontend-expert

Expert frontend developer specializing in React, Next.js, Vue, Angular, TypeScript, Tailwind CSS, and modern UI frameworks. Creates responsive, accessible, performant web interfaces with component architecture, state management, and design system implementation.

## Installation

### Claude Code
```bash
cp -r frontend-expert ~/.claude/skills/
```

### MiMoCode / OpenCode
```bash
cp -r frontend-expert ~/.opencode/skills/
```

### Cursor
Add to your project's CLAUDE.md:
```markdown
Load the frontend-expert skill from ~/.opencode/skills/frontend-expert/SKILL.md
```
