# typescript-pro

Implements advanced TypeScript type systems, creates custom type guards, utility types, and branded types, and configures tRPC for end-to-end type safety.

## Installation

### Claude Code
```bash
cp -r typescript-pro ~/.claude/skills/
```

### MiMoCode / OpenCode
```bash
cp -r typescript-pro ~/.opencode/skills/
```

### Cursor
Add to your project's CLAUDE.md:
```markdown
Load the typescript-pro skill from ~/.opencode/skills/typescript-pro/SKILL.md
```
