# Systematic Debugging — Diagnóstico Sistemático

Diagnostica bugs y errores de forma sistemática antes de intentar fixes aleatorios que gastan tokens en iteraciones innecesarias.

## Token Economy
- Buscar la CAUSA raíz PRIMERO (grep/log, no guesses)
- Proponer UN fix por vez, esperar confirmación
- Nunca modificar archivos sin entender primero el error
