## Asset Type Legend
- **Framework** — Core agent orchestration library
- **SDK** — Language-specific client/server library
- **Platform** — Hosted or self-hosted service
- **Tool** — Single-purpose utility (VAD, TTS, etc.)
- **Template** — Starter project / boilerplate
- **Protocol** — Specification / communication standard
- **Registry** — Curated list / discovery service
- **Course** — Educational material
- **Benchmark** — Evaluation framework
