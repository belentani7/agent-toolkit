# backend-expert

Expert backend developer specializing in Node.js, Python, Go, Rust APIs, microservices, databases (PostgreSQL, MongoDB, Redis), authentication, and cloud infrastructure. Builds scalable, secure, production-grade server applications.

## Installation

### Claude Code
```bash
cp -r backend-expert ~/.claude/skills/
```

### MiMoCode / OpenCode
```bash
cp -r backend-expert ~/.opencode/skills/
```

### Cursor
Add to your project's CLAUDE.md:
```markdown
Load the backend-expert skill from ~/.opencode/skills/backend-expert/SKILL.md
```
