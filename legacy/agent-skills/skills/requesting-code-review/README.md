# Requesting Code Review — Pedir Review Estratégico

Solicitar revisión en puntos estratégicos (no tras cada micro-cambio) para evitar spam y desperdicio de tokens en reviews triviales.

## Token Economy
- Pedir review solo después de completar una fase significativa
- Nunca pedir review de changes < 5 archivos
- Incluir siempre qué se quiere que revise específicamente
