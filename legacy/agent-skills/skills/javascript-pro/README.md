# javascript-pro

Writes, debugs, and refactors JavaScript code using modern ES2023+ features, async/await patterns, ESM module systems, and Node.js APIs.

## Installation

### Claude Code
```bash
cp -r javascript-pro ~/.claude/skills/
```

### MiMoCode / OpenCode
```bash
cp -r javascript-pro ~/.opencode/skills/
```

### Cursor
Add to your project's CLAUDE.md:
```markdown
Load the javascript-pro skill from ~/.opencode/skills/javascript-pro/SKILL.md
```
