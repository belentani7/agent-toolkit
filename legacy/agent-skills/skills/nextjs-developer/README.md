# nextjs-developer

Use when building Next.js 14+ applications with App Router, server components, or server actions. Invoke to configure route handlers, implement middleware, set up API routes, add streaming SSR, write generateMetadata for SEO, scaffold loading.tsx/error.tsx boundaries, or deploy to Vercel.

## Installation

### Claude Code
```bash
cp -r nextjs-developer ~/.claude/skills/
```

### MiMoCode / OpenCode
```bash
cp -r nextjs-developer ~/.opencode/skills/
```

### Cursor
Add to your project's CLAUDE.md:
```markdown
Load the nextjs-developer skill from ~/.opencode/skills/nextjs-developer/SKILL.md
```
