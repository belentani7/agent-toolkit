- [ ] 0 repos en `~/repos/` raíz suelta — todos dentro de una carpeta de categoría.
- [ ] 0 duplicados funcionales (mismo propósito, ≥80% overlap) detectados en `01-ECOSYSTEMS/`, `03-AI/`, `04-MUSIC/`.
- [ ] 0 repos sin `remote` configurado salvo en `07-ARCHIVE/` y `08-SANDBOX/`.
- [ ] `_TRASH/` vacío (todo purgado o movido definitivamente).
- [ ] `08-SANDBOX/` vacío o con ≤3 repos y cada uno con issue de decisión fechada.
- [ ] Naming 100% lowercase-kebab.
- [ ] README índice en raíz `~/repos/README.md` mapeando cada ecosistema a sus repos.
- [ ] Cada repo en `07-ARCHIVE/` tiene flag de solo-lectura y fecha de archivado en su README.
